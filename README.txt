CREATIV — SYDNEY DIGITAL MARKETING AGENCY
Static website package prepared for GitHub Pages.

DEPLOYMENT:
1. Create a GitHub repository. For a project site, any repository name can be used.
2. Upload the CONTENTS of this folder (index.html, styles.css, assets, services, 404.html) to the repository root.
3. In repository Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
4. Wait for GitHub Pages to publish the site. The URL depends on the GitHub account and repository name.
5. Once the final public URL is known, add canonical URLs and a sitemap with that exact URL if desired.

NOTES:
- This is a static HTML/CSS site; no Node.js, Next.js or build command is required.
- The six service pages are separate folders with index.html files and relative navigation links.
- Google Business Profile link and an embedded Google Maps location are included on the homepage.
- The supplied logo image has a solid black rectangular background, so it was intentionally not embedded to avoid showing an unwanted black box or altering the logo.
- Hosting-provider names are not included in the public website copy.
- Confirm the address, phone, email and Google Business Profile destination before publishing.
